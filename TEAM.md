## Начать

После приглашения в приватный репозиторий:

```text
git clone https://github.com/Temirlan222/FinalSDP.git
cd FinalSDP
git switch -c codex/your-part
```

Прочитать README и CONTRACT. Запустить `build.ps1 -Test`, затем `build.ps1 -Web`.

## Что объяснить

**Temirlan:** цепочку Ribbon(GiftWrap(book)), неизменность книги, роль DiscountStrategy/PriceCalculator, различие процентной и пороговой скидок, округление и порядок расчёта. Примеры: 2600 → 2340; 4999/5000 → 4999/4500.

**Shalkar:** фабричный метод createProduct и его переопределения; registry map в Facade не является самим Factory Method. Builder создаёт весь бокс, Decorator оформляет один подарок. Зачем List.copyOf и проверка build. Практика: самостоятельно добавить новый вид подарка и тест; карточку зарегистрировать в UI.

**Murager:** publisher Order и два subscriber; subscribe/unsubscribe; почему нельзя пропустить PACKING; как Facade упрощает клиенту вызовы подсистем. Практика: самостоятельно добавить наблюдателя либо изменить и протестировать сценарий статусов, согласовав API с UI.

**Всем:** пройти полный сценарий, знать ограничения, сравнить код и UML, показать собственные изменения. Не делать формальные правки ради числа коммитов.
